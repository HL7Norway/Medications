# Medications - Medication Profiles (HL7 Norway / Helse Nord)

FHIR R4 Implementation Guide profiles for medications (VKP / Valferdsteknologi).

## Description

This repository contains FHIR R4 StructureDefinition profiles, CodeSystems, ValueSets,
and examples for medication profiles used in the Norwegian eHealth infrastructure.

## Structure

- `StructureDefinition/` — FHIR profiles (e.g. sfm-Medication.StructureDefinition.xml)
- `CodeSystems/` — CodeSystem definitions (e.g. SFMAdmByCodeSystem.xml)
- `ValueSet/` — ValueSet definitions
- `Examples/` — example resources
- `ImplementationGuide/` — IG configuration
- `NamingSystem/` — naming system definitions
- `Script/` — helper scripts
- `Images/` — diagrams and screenshots

## Files

- `sfm-Medication.StructureDefinition.xml` — Medication profile (status: draft)
- `SFMSectionTypes.xml` — section type codesystem

## Versioning

Profiles follow the naming convention: `vkp-<name>-v<version>.structuredefinition-<type>.xml`
